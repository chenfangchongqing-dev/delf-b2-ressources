# DELF B2 Ressources

Site pédagogique structuré selon les quatre compétences du DELF B2 :

- CO — Compréhension de l’oral
- CE — Compréhension des écrits
- PE — Production écrite
- PO — Production orale

Les pages PE et PO proposent une lecture pédagogique des critères d’évaluation et des attentes du niveau B2.

> Important : les documents réservés aux examinateurs-correcteurs ne sont pas reproduits ni redistribués sur ce dépôt public. Le site reformule les critères à des fins pédagogiques.
